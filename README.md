# SubzFree — Free AI Caption Generator

> 100% Free AI captions for Reels, Shorts & Videos. No watermark. No subscription. 22 Indian languages.

🔗 **Live:** [subzfree.vercel.app](https://subzfree.vercel.app)

---

## Features
- ✅ AI-powered Hinglish + 22 language transcription
- ✅ 60+ animated caption styles (Hormozi, Neon, Karaoke...)
- ✅ Word-level editing & timing control
- ✅ 4K export — No watermark (watch 30-sec ad)
- ✅ No login required
- ✅ Video stays on your device (browser-side processing)

## Tech Stack
- Pure HTML + CSS + JavaScript
- No framework, no build step
- Deployed on Vercel (free tier)
